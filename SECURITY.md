# Reporting a security issue

Contact [@Grantfoldrh on X](https://x.com/Grantfoldrh) and ask for a private contact route before sending sensitive details. Direct messages depend on the account's settings. Do not post exploitable details or wallet history in a public issue.

Never share a seed phrase, private key, production environment file, session cookie, database export or signed payment authorization. A report can start with the affected component, a concise description and a reproduction using an unfunded test account or isolated fixtures.

Production agent wallets use server-held encrypted keys. Preserve the wallet encryption key with its database. Pause the agent and resolve submitted orders before changing signing material. Normal support is documented at [grantfold.xyz/support](https://grantfold.xyz/support).

The project is in early access. No independent security audit or guaranteed response time is claimed.
